# Shopping Cart V2 — PlayStation Store

An ASP.NET MVC 5 shopping-cart coursework project that models a PlayStation game store. The application includes game categories, product and option management, customer records, checkout, purchases, and an admin area.

## Tech

- C# and ASP.NET MVC 5
- Entity Framework 6
- SQL Server LocalDB
- Razor views, Bootstrap, and jQuery

## Run locally

1. Open `ShoppingCartV2.sln` in Visual Studio.
2. Restore NuGet packages from `packages.config`.
3. Create or attach the LocalDB database expected by `Web.config`.
4. Build and run with IIS Express.

> The local database files, generated build output, and an embedded duplicate source folder are intentionally excluded from this repository.
